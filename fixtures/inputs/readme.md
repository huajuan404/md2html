# md2html

> **Markdown 适合写,HTML 适合读。md2html 让你继续写 Markdown,AI 重新组织成 HTML。**

把 ChatGPT / Claude / Codex / Gemini 输出的长 Markdown、研究笔记、推文整理、报告,实时投影成可读、可分享、可下载的 HTML 页面。

**3 个独立旋钮 · 9 份骨架 · 4 个一键预设 · 0 个 API key · 单文件 HTML 下载 · 本地优先**

## 为什么需要这个

灵感来自 [Karpathy 关于 AI HTML 输出的那条 X 长帖](https://x.com/karpathy/status/2053872850101285137)(397 条回复)—— AI 输出正在从纯文本 → Markdown → HTML → 更高带宽的视觉媒介演进。

但两件事的好处刚好相反:

| Markdown | HTML |
|---|---|
| 适合人类编辑 | 适合人类消费 |
| 纯文本、可 diff、好维护 | 有布局、有视觉层级 |
| 复制到推特里像源代码 | 截图就是一张海报 |
| 同样的内容投不同平台都要重排 | 一次产出多渠道适配 |

普通 Markdown 渲染器把"适合编辑"的格式直接当成"适合消费"的格式——结果两头都不讨好,HTML 只是"Markdown 加了点字号差异"。

md2html 不做这个。**它继续让你用 Markdown 编辑,但用 AI 在产出 HTML 这一步重新组织内容**:决定先说什么、再说什么、一屏装多少、看起来什么风格。

## 谁该用

- 用 ChatGPT / Claude / Codex / Gemini 输出长 Markdown,想转成像样页面的人。
- 把研究笔记、推文整理、访谈记录、报告变成阅读页 / 简报 / 卡片流的人。
- 想保留 Markdown 可编辑性,但希望输出不只是"文档预览"的人。

## 谁不该用

- 只需要普通 Markdown 编辑器的人——用 Typora / StackEdit 就好。
- 需要多人实时协作的人——本工具是单人本地优先。
- 需要手写 HTML/CSS 的前端开发者——本工具不让你编辑 HTML。

## 三个独立旋钮

工具栏顶部三个下拉,互不影响:

### 逻辑:内容的骨架

回答"先说什么、再说什么":

- **原文顺序**:按 Markdown 原结构铺。
- **结果先行**:AI 把结论抽到顶上,证据后置。
- **时序展开**:AI 还原"背景 → 问题 → 方案 → 结果"的论证流。

### 密度:一屏装多少

回答"怎么把内容铺进屏幕":

- **宽松**:长滚动页,留白宽。
- **紧凑**:长滚动页,多栏分区。
- **一屏一页**:分页,一屏一个核心观点。

### 主题:视觉风格

控制配色、字体、阴影等纯样式。提供三套内置主题,未来可扩展。

## 一键预设

不想拨三个下拉?四个一键预设:

| 预设 | 适合场景 |
|---|---|
| Faithful | 验证解析、对照原文 |
| Reader | 文章、研究笔记、访谈稿 |
| Brief | AI 长回答、决策备忘、研究报告 |
| Deck | 简报、传播卡片、教学序列 |

## 5 个核心设计选择

### 1 · AI 只在重排这一步参与,不直接产出 HTML

AI 的工作被严格限定为"读懂 Markdown 段落的角色,把它们塞进骨架的对应区"。HTML 由确定性 renderer 产出。这避免了 AI 输出失控、source map 失守,也避免产品退化成另一个"AI 一次性吐 HTML"的工具。

### 2 · 改错别字不触发 AI 重排

只有改变文档"形状"的编辑(加段、加标题、删段、改 heading 级)才触发 AI 重新组织。改个词、修个标点、句内调整—— AI 完全不参与,渲染稳定,不浪费 token。

### 3 · 每个 HTML 区块都知道自己来自 Markdown 哪几段

右侧 HTML 的每个主要区块都标注了"我来自第几行到第几行"。点击右侧任一区块,左侧自动跳到对应源文本。**这是同类工具不做的事**——也是 md2html 的护城河。

### 4 · UI 语言和内容语言独立

切换工具自身的语言(中 / 英)不影响输出。中文 Markdown 永远产出中文标签的 HTML,不管编辑器 UI 是中是英——因为导出的 HTML 是给读者的,不是给编辑者的。

### 5 · 骨架由产品团队预写,不让用户写

每个(逻辑, 密度)组合对应一份预写的骨架配置,声明"这种形态下页面应该有哪几个区"。9 份骨架共同决定输出形态。用户只选预设或拨三轴,不需要懂"骨架"是什么。

## 怎么用

1. 浏览器打开 md2html。
2. Markdown 粘到左侧,或上传 `.md` 文件。
3. 工具栏选预设(或独立调三轴)。
4. 右侧实时显示。点击右侧节点,左侧会高亮源文本。
5. 点下载,得到单文件 HTML。

## 离线、本地、无需账号

- 编辑、渲染、下载全在浏览器里完成。
- 不上传任何内容到云端。
- AI 重排需要联网调 LLM,但延迟触发、缓存命中跳过,控制成本。
- 导出 HTML 内联所有 CSS/JS,浏览器双击即开。
